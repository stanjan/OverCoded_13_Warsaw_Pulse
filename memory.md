# Project memory — Warsaw AI ("Warszawa Pulse")

## End goal

A minimalistic web app for an open data hackathon that helps people living in
Warsaw find events and the transport to get there.

## What we're building

- Ask the AI assistant about events in the city.
- See the events you searched for on the map.
- Get transport directions to the chosen event.
- Built on Warsaw open data.
